типы данных:

Number (NuN) (число) (+)
string (строка) 
Boolean (true/false) (!!)
Undefiend (незнаем)
Null (пусто, как сукун)
Symbol (уникальный идентификатор)
BigInt (n в конце числа прописываем чтобы большие числа корректно отображались)
Object ([] (Array),{} (object), Function)

динамическая типизация (добавление переменых во время выполнения программы)
typeof ключевое слово которое позволяет узнать тип переменых

преобразовние переменых, джава скрипт может сам определять и преобразовывать один тип даных в другой если видит к
этому предпосылки.
например:
-, *, /, <, >, === - все приводится к числу
ИСКЛЮЧЕНИЕ! + все приводится к строке

пустые значения (в логическом типе данных они автоматически записываются как false)
0, -0, 0n, "", null, undefined, NuN, false

операторы сравнения -
нестрогая == ("5" == 5  ==> true)
строгая === (5 === '5' ==> false) 
НЕ ПУТАТЬ С = (это просто присвоить значение)
при строгом cравнении сравнивается и значение и тип данных
при не строгом сравнении сравниваются только значения данных

переменные - значения которые можно назначить с помощью ключей вроде var let и const
let современный вариант var и ее можно переназначить(что полезно для функций)
